# MediRAG Evaluation Reports

This directory stores consolidated evaluation summaries, benchmark scorecards, and cross-model comparison reports.

---

## Report Artifacts (Planned)

- **Comprehensive Scorecards**: Markdown and PDF summaries combining retrieval recall, claim-level groundedness, citation entailment, and expert grades.
- **Regression Analysis Reports**: Per-query movement tables documenting changes between system versions (e.g., v1.0 baseline vs v2.0 modernized).
